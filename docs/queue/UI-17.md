# `UI-17` — the centre panel shows what each source needs

[← Builder Queue index](../BUILDER_QUEUE.md)

🟠 **P1 (GA).** Filed 2026-09-29 from the owner's return-checklist sitting. Design settled in conversation the same day; the owner took every recommendation below.

## What the owner asked

> *"The right part of that panel is labelled 'Total Plays', 'Top Track' & 'Top Artist'. This part of the panel should have a toggle to show/hide it. It's not valuable enough to show by default all the time. The queue part on the left side of this panel really only makes sense for the File Player input type. By default, history should show for: Vinyl, File Player, USB Audio. Radio should default to the Radio Control panel, but be toggleable to history. Bluetooth should default to a panel that allows connection to a device (if no device is currently selected) and history if already connected."*

## Today (measured 2026-09-29)

- Radio swaps the whole centre panel for `RadioControlPanel` via a layout-level `RadioPanelToggleService` (`MainLayout.razor:1084`, `:1198`). The **Queue** nav pill hides it; `QueueHistoryPanel` then shows an extra **Radio** tab. Two mechanisms for one switch.
- The **Queue** tab shows for every source; File Player opens on Queue, the rest on History (`QueueHistoryPanel.razor:760-773`).
- Right column: History → stats tile (Total Plays / Top Track / Top Artist); Queue → Queue Total, **Up Next** (duplicates the left list), Save as playlist.
- Bluetooth has no connect UI in the panel; its source chevron navigates to `/bluetooth`.
- A tapped tab sticks until the source changes (`_userOverrodeTab`).

## The spec

**One tab strip across the top of the centre panel for every source.** It replaces both the layout-level radio switch and today's per-panel tabs.

| Source | Opens on | Tabs |
|---|---|---|
| File Player | **Queue** if it has tracks, else **History** | Queue · History |
| Vinyl, USB Audio (`GenericUSB`), Test Tone | History | — (no strip beyond the Stats chip) |
| Radio family (`RTLSDRCore`; `Radio`/`RF320` until `AUD-16` removes them) | **Radio** controls | Radio · History |
| Bluetooth, no device connected | **Connect** | Connect · History |
| Bluetooth, device connected | **History** | History · Devices |

1. **Stats chip.** A small `Stats` toggle in the strip, **off by default**, shows/hides only the Total Plays / Top Track / Top Artist block. Off → the history list takes the full width. Persisted as a **config-store UI preference** (one console-wide value), so it survives restarts, deploys and kiosk-profile resets.
2. **Queue view right column.** Keep Queue Total and Save as playlist; **drop Up Next** (it repeats the left list). The queue list uses the width.
3. **Queue is File Player only** as a tab. The kebab (Add Files / Load Playlist / Clear All) goes with it.
4. **The Queue nav pill** shows the queue view **whatever the source** — the queue persists across sources, and viewing it must not interrupt what is playing. It does not switch source.
5. **Radio.** Radio controls are a tab, not a layout swap. The source chevron still jumps to the Radio tab. Switching *to* the radio source always opens on Radio; a tapped History tab sticks until the source changes. Retire `RadioPanelToggleService`'s show/hide calls in `MainLayout` once nothing needs them.
6. **Bluetooth Connect panel.** Paired devices with Connect buttons, plus **Scan for new devices** with inline pairing. Forget-device and adapter details stay on `/bluetooth` (link from the panel). **Auto-switch:** a device connecting while on Connect → History; the device disconnecting → Connect — unless the owner tapped a tab since the source became active (the existing override rule). All through the existing `/api/bluetooth` endpoints, so it stays on Radio Console's adapter (`hci0`) per the RotaryPhone boundary doc. The **Devices** tab (when connected) is the same panel, for switching or disconnecting the phone.
7. **Vinyl / USB Audio:** history only, no source-specific panel.

## Verification

bUnit tests over the source → default-tab matrix (including the File Player empty/non-empty split and both Bluetooth states), the override rule, the Stats chip default and its persistence call, and the absence of the Queue tab on non-File-Player sources. Owner UAT at the panel: each source's default view, the Stats chip, the Queue pill on Radio, and a Bluetooth connect → auto-switch to History.
