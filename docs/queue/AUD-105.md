# `AUD-105` — `POST /api/radio/band` lands on a band edge, not the band's remembered frequency

[← Builder Queue index](../BUILDER_QUEUE.md)

🟢 **P3. Filed 2026-10-11 by the `AUD-99` Builder** from its box UAT, on the coordinator's instruction to log it as
a row and not fix it inside `AUD-99`. Not caused by `AUD-99`. The mechanism below was read from code on branch
`feat/aud-99-hf-direct-sampling` (`bba19a4f`); the symptom was measured on the box.

## Measured (box `radio`, build `341f264`, 2026-10-11 23:01–23:09 UTC)

| Request | Before | After |
|---|---|---|
| `POST /api/radio/band {"band":"AM"}` | FM 97.745 MHz | **AM 1710 kHz** (the band's top edge) |
| `POST /api/radio/band {"band":"SW"}` | AM 1710 kHz | SW **1710 kHz** (1.71 MHz is inside SW's 1.6–30 MHz, so the frequency was kept) |
| `POST /api/radio/band {"band":"FM"}` | SW 1710 kHz | **FM 87.5 MHz** (the band's bottom edge), not the 97.745 MHz the radio was on before AM |

The owner's station had to be restored by hand with `POST /api/radio/frequency`.

## Read from code (not measured)

- `IRadioBandMemory` / `RadioBandMemoryService` (`src/Radio.Infrastructure/Audio/Services/RadioBandMemoryService.cs`)
  is used by the encoder's `SourceSelectorService` and `PresetSelectorService` and by `PreferencesPersistenceService`.
  `RadioController.SetBand` (`src/Radio.API/Controllers/RadioController.cs`, `[HttpPost("band")]`) calls
  `SDRRadioAudioSource.SetBandAsync` directly and does not consult it. Grep finds no reference to band memory in
  `SDRRadioAudioSource.cs`.
- Which code chooses the edge frequency (a clamp of the old frequency into the new band's range, or the preset's
  start) has **not** been traced. That is the first step of the plan.
- Whether the panel's band buttons use this route (and so show the same symptom to the owner) has not been checked.

## Scope (for the Planner)

A band change through the API recalls the band's remembered frequency (and step, cf. `AUD-95`) the same way the
encoder does, through one shared path. It falls back to the band's default when nothing is remembered.
Coordinate with `AUD-95` (the step on a band-crossing tune) and `AUD-102` (band edges).
