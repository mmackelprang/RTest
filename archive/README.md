# Archive

This folder is a historical record and is not maintained. It holds the plans, handoffs, research, UAT evidence
and work-queue history written while Radio Console was built, up to the v1.0.0 release. Statements here were
true when they were written. Many have since been superseded, and paths or links inside these files may point
at locations that no longer exist. For current documentation, start at [`../docs/README.md`](../docs/README.md).
