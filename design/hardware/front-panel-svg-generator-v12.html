Importing into Cricut Design Space
  1. Upload → Image → browse to the downloaded .svg. It comes in as a grouped image; do not use "Print Then Cut".
  2. Check the size. Select the group; it should read 16 in × 6 in. Design Space interprets unitless SVG coordinates at 72 dpi, which is what output.dpi is set to, so the panel arrives at true scale. If a future version of Design Space ever reads it at 96 dpi the import would land at 12.188 × 4.5 — change output.dpi to 96, re-download, re-import.
  3. Ungroup to get the colour layers listed above, then select them and click Attach so Design Space keeps them in position instead of re-nesting them on the mat. The vinyl label spec is already a single colour, so it imports as one layer and needs no attaching.
  4. Set Linetype = Draw (pen) on the outline, crosshair and label layers. Delete or hide the blue reference layer before drawing.
  5. Because the panel is 16 in wide, use a 12 × 24 in mat and rotate the group 90°, or split it across two mats.

Everything the old file used that Design Space silently dropped — a <style> block with CSS classes, <defs>, <textPath> on an arc, live <text> elements and inch-suffixed dimensions — is gone. Every element now carries its own presentation attributes and plain numeric coordinates.

Spec reference

Feature types: circle (x, y, diameter) · slot (centerX, centerY, width, height, cornerRadius) · cornerMounts (diameter, insetX, insetY) · vesa (centerX, centerY, pitchMm, diameter, showGuide) · label (text, centerX, centerY, baselineOffset, size, font, anchor).

Labels: horizontally centred on centerX; the baseline sits baselineOffset inches below centerY, which is the knob centre. Set baselineY instead to place the baseline absolutely. Glyphs are emitted as closed outline paths — no font is needed on any machine that opens the file.

Fonts (font): sans, sans-bold (Liberation Sans / Arial metrics) · inter, inter-medium · montserrat · poppins, poppins-light · barlow (Barlow Semi Condensed) · space-grotesk · rajdhani · oswald. All are open-licence (SIL OFL) and embedded in this page as outline data.

Sizing: size is the em size, so the same value looks different across faces. Use capHeight instead to specify the actual height of a capital letter in inches — the generator converts it per font, so labels stay optically identical when you swap fonts.

Vinyl label types: ring (centerX, centerY, innerDiameter, outerDiameter) — a filled annulus that drops over a drilled hole and self-centres on it · cornerBracket (corner: tl/tr/bl/br, arm, weight) · edgeTick (edge: left/right/top/bottom, at, length, weight) · arrow (x, y, size). All are filled shapes, sized for weeding and transfer.

Label extras: uppercase forces caps; tracking adds letterspacing as a fraction of the em (0.10 = +10%), inserted between glyphs only so the string still centres on its visible extent.

Crosshairs are generated automatically for every production hole (circle, cornerMounts, vesa). output.crosshairExtend is how far each arm reaches past the hole edge, in inches.

output: dpi (user units per inch, 96 default) · includeReference · crosshairs · crosshairExtend · strokeWidth (user units) · precision · colors.

Anything with "referenceOnly": true is drawn in the reference colour and can be excluded from the file entirely with "includeReference": false.
